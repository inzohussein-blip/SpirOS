# 🗺️ خريطة طريق SpirOS (النسخة 2)

> مساحة ثانية معزولة ومشفّرة داخل هاتفك، بدون روت، على **أندرويد 14 وما بعده، وعلى أي واجهة** (MagicOS، One UI، HyperOS، ColorOS، Pixel...).

## القرارات المعتمدة

| البند | القرار |
|---|---|
| الأهداف | تطبيقات أندرويد معزولة، وخزنة ملفات وصور مشفرة، وتصفح خاص ضد التتبع، ونظام كامل (VM) |
| المسار الهندسي | **مساران متوازيان**: المسار A (المساحة المعزولة) هو المنتج الأساسي، والمسار B (محرك QEMU) مسار بحثي |
| بيئة التطوير | **الهاتف فقط**: كل البناء يتم على GitHub Actions، ويُحمَّل الـ APK من صفحة Actions |
| النشر | استخدام شخصي + مفتوح المصدر بترخيص **GPL-2.0-or-later** (متوافق مع QEMU) |
| الحزمة | `com.spiros.app` · Kotlin · Jetpack Compose · minSdk 30 (يُثبَّت من أندرويد 11) · **الهدف والاختبار: أندرويد 14+** · targetSdk 35 |
| التوافق | **نظام عام**: لا كود خاص بشركة أو واجهة؛ كل ميزة تُكتشف أثناء التشغيل ولها بديل |

## مبدأ "النظام العام" (يعمل على أي واجهة)

1. **واجهات أندرويد الرسمية فقط** (Keystore، BiometricPrompt، DevicePolicyManager، VpnService). لا اعتماد على ميزات خاصة بشركة معينة.
2. **فحص القدرات أثناء التشغيل**: شاشة "توافق الجهاز" (`compat/DeviceCompat.kt`) تسأل النظام عمّا يدعمه، ولا تفحص اسم الشركة.
3. **بديل لكل ميزة**: إذا كانت الواجهة تمنع Work Profile، تستمر الخزنة والمتصفح والدرع داخل SpirOS نفسه. وإذا لم توجد بصمة، يعمل الفتح بالرمز. وإذا لم يوجد تسريع للمحاكاة، يعمل المختبر بالمحاكاة البرمجية.
4. **أندرويد 14 هو الهدف، و11 هو الحد الأدنى للتثبيت**: رُفع الحد الأدنى الأول (14) لأن التطبيق لم يكن يُثبَّت على الهواتف ذات النسخ الأقدم. الواجهات الأحدث من أندرويد 11 محمية بفحص للإصدار، وأداة lint في GitHub Actions تمنع أي استدعاء غير محمي.

## لماذا مساران؟

بدون روت لا يستطيع أي تطبيق استخدام تسريع العتاد للأجهزة الوهمية (KVM/pKVM/AVF).
لذلك QEMU يعمل بالمحاكاة البرمجية (TCG)، وأندرويد كامل بداخله سيكون بطيئًا جدًا على أي هاتف متوسط.
**الحل:** نبني المنتج اليومي على آليات أندرويد الرسمية للعزل (Work Profile)، ونطوّر محرك QEMU بالتوازي
لتشغيل نظام لينكس خفيف، ونقيس أداءه بأرقام حقيقية قبل أي محاولة لتشغيل أندرويد كامل.

## الهيكل

```
SpirOS.apk
├── 🔐 Vault        مصادقة PIN/بصمة، مفاتيح Android Keystore، تخزين مشفر، FLAG_SECURE
├── 🏠 Launcher     الواجهة الثانية: تعرض فقط تطبيقات المساحة المعزولة
├── 🧱 Space        Work Profile، و SpirOS هو Profile Owner فيه
├── 🛡️ Shield       VpnService محلي لحجب المتتبعات (DNS)، وتعطيل خدمات جوجل داخل المساحة
├── 🌐 Browser      متصفح خاص (GeckoView أو WebView مقسّى) يُمسح عند الإغلاق
└── 🧪 Engine       QEMU عبر NDK/JNI ← لينكس خفيف ← عرض في SurfaceView
```

```
app/src/main/
├── java/com/spiros/app/
│   ├── ui/        شاشات Compose
│   ├── vault/     المصادقة والتشفير            (المرحلة A1)
│   ├── space/     إدارة Work Profile            (المرحلة A2)
│   ├── launcher/  الواجهة الثانية              (المرحلة A3)
│   ├── shield/    VPN و DNS                    (المرحلة A4)
│   └── engine/    واجهة Kotlin لمحرك QEMU      (المسار B)
└── cpp/
    ├── spiros_jni.cpp   جسر JNI
    └── qemu_core/       كود QEMU المعدّل        (المرحلة B1)
```

- [x] الفتح بالبصمة عبر `BiometricPrompt` مع مفتاح مرتبط بالبصمة، يُلغى تلقائيًا عند إضافة بصمة جديدة

- [x] استيراد من أي مصدر (منتقي ملفات النظام)، مع خيار حذف الأصل، وتصدير نسخة مفكوكة التشفير

- [ ] تغيير الرمز، ومهلة قفل قابلة للتعديل، ومشغّل فيديو داخلي

### A2: محرك العزل (Work Profile) ✅

- [x] عرض تطبيقات المساحة وتشغيلها عبر `LauncherApps`، وهي واجهة عامة تعمل مع أي تطبيق وعلى أي واجهة
- [x] استنساخ التطبيقات من الهاتف إلى المساحة (`installExistingPackage`): نفس التطبيق، ببيانات وحسابات منفصلة
- [x] تجميد تطبيق أو كل التطبيقات (`setPackagesSuspended`)، والإزالة من المساحة (حذف صامت، أو إخفاء إن رفض النظام)
- [x] منع النسخ واللصق بين المساحة والهاتف، وإخفاء أيقونة SpirOS داخل المساحة
- [x] حذف المساحة كاملة. مسح الخزنة أو رمز الطوارئ يحذف المساحة أيضًا
- [x] استئناف المساحة إذا كانت متوقفة، أو إرشاد المستخدم لفعل ذلك من الإعدادات السريعة
- [x] **ملف عمل موجود لتطبيق آخر:** أندرويد يسمح بملف عمل واحد، ولا يستطيع حذفه إلا مالكه أو المستخدم. لذلك يكتشف SpirOS نوعه (عمل، أو نسخ مزدوجة، أو مساحة خاصة، على أندرويد 15+) ومن يديره (Shelter أو Island أو Insular أو تطبيق شركة أو نسخة SpirOS سابقة)، ويعرض تطبيقاته ويفتحها، ويوقفه مؤقتًا إن سمح النظام، ويفتح شاشة الحذف في الإعدادات مع الخطوات
- [ ] تثبيت APK مباشرة داخل المساحة، وتجميد تلقائي عند قفل SpirOS
- ⚠️ إذا كانت الواجهة تمنع Work Profile أو يوجد ملف عمل آخر، تشرح شاشة المساحة السبب، ويعمل SpirOS بالبديل الداخلي

### A3: الواجهة الثانية (Launcher) ✅

- [x] **حسابات لينكس بدون طرفية:** إضافة حساب بكلمة مرور وصلاحية مدير (sudo)، وتغيير كلمة مرور أي حساب بما فيه root، وجعل حساب مديرًا أو إلغاء ذلك، وحذف حساب، واختيار الحساب الذي يعمل به سطح المكتب (proot --change-id). كلمات المرور تُمرَّر عبر stdin ولا تظهر في أوامر النظام
- [x] سكربت تشغيل سطح المكتب صار جزءًا من التطبيق نفسه، ويُحدَّث داخل لينكس قبل كل تشغيل

## الأداء وتوفير البطارية ✅ (الإعدادات ← الأداء وتوفير البطارية)
- [x] **المساحة:** تعطيل خدمات Google (توفير 300 إلى 500 ميغابايت)، وإيقاف المساحة مؤقتًا، وتجميد كل تطبيقاتها أو إلغاء تجميدها
- [x] **لينكس، الوضع الخفيف** (مفعّل افتراضيًا): بلا مؤثرات الشفافية والظلال (compositing)، وتحريك النوافذ بإطار فقط، وبلا مدير الطاقة وشاشة التوقف وناقل إمكانية الوصول
- [x] **العارض:** ينسخ المنطقة المتغيرة فقط بدل الشاشة كاملة، وبحد أقصى لعدد الإطارات (15 أو 30 أو 60، والافتراضي 30)
- [x] **الدقة:** خيار جديد 960×540 للهواتف المتوسطة، ويُحفظ الاختيار
- [x] **التجميد في الخلفية** (مفعّل افتراضيًا): يرسل SIGSTOP لبرامج لينكس والذكاء الاصطناعي والمختبر عند الخروج من SpirOS، وSIGCONT عند العودة. يمكن إيقافه لإبقاء MT5 يعمل
- [x] **وضع البرنامج الواحد:** الطرفية، أو مدير الملفات، أو المحرر، مع مدير نوافذ فقط
- [x] **الذكاء الاصطناعي:** الأنوية السريعة فقط (تُكتشف من ترددات المعالج)، وحجم السياق 1024 أو 2048 (الافتراضي) أو 4096

## المظهر وسهولة الاستخدام ✅
- [x] **المظهر** (الإعدادات ← المظهر، ويُطبَّق فورًا): الثيم (حسب النظام، أو داكن، أو فاتح)، والألوان (ألوان SpirOS، أو Material You من خلفية الهاتف في أندرويد 12+)، والأسلوب (أنيق بتدرجات وظلال، أو بسيط مسطح). أيقونات شريط الحالة تتبع الثيم

- [x] **زر الدرع في الإعدادات السريعة** (Quick Settings tile) لتشغيل الدرع أو إيقافه دون فتح التطبيق. يُخفى في وضع التمويه
- [x] **بحث في الإعدادات** يُظهر الخيارات المطابقة فقط

## حزمة التخفي والأمان والإبهار ✅
- [x] **زر الذعر (Panic):** زر أحمر في الرئيسية وشريط لينكس، وزر في الإعدادات السريعة، وزر في إشعار التحكم. يمسح المفتاح من الذاكرة، ويقفل، ويغلق التطبيق ويحذفه من التطبيقات الأخيرة، ويعود لشاشة الهاتف، ثم يوقف لينكس والذكاء الاصطناعي والمختبر ويمسح بيانات المتصفح. **لا يحذف أي بيانات** (الحذف لرمز الطوارئ)
- [x] **الذعر عند قلب الهاتف على وجهه** (اختياري)
- [x] **إشعار تحكم دائم** (خدمة foreground) أثناء تشغيل لينكس أو الذكاء الاصطناعي أو المختبر: فتح · تجميد/استئناف · إيقاف الكل · ذعر. مخفي من شاشة القفل، ويمنع أندرويد من إيقاف لينكس في الخلفية
- [x] **ثيم Cyber:** أسود AMOLED حقيقي مع أخضر فسفوري أو سماوي نيون
- [x] **قفل خفي:** شاشة سوداء ببصمة فقط وبلا أي نص. لمسة = البصمة، وضغط مطوّل = لوحة الأرقام، والخطأ يظهر بالرجّة فقط
- [x] **لوحة مؤشرات حية** في الرئيسية: رام الهاتف، وذاكرة لينكس والذكاء والمختبر (قياس VmRSS حقيقي)، وحجم الخزنة المشفّرة، ودرجة الأمان (0 إلى 100) حسب الحمايات المفعّلة
- [x] **شاشة إقلاع رقمية:** مطر رقمي بأسلوب Matrix، وشعار SpirOS ينبض، و**سجل الإقلاع الحقيقي** تحته، واهتزاز عند نجاح الإقلاع
- [x] **صورة داخل صورة** لسطح مكتب لينكس (ميزة أندرويد الرسمية، بدون صلاحية "الظهور فوق التطبيقات")
- [x] **رمز سري للآلة الحاسبة** (مثل `1995×7` ثم =)، تُحفظ بصمته فقط. يكشف SpirOS ثم يطلب الرمز، أو يفتح مباشرة إذا كان القفل معطلًا
- ✖️ لم تُنفَّذ النافذة العائمة ولا اللوحة الجانبية عمدًا: تحتاجان صلاحية "الظهور فوق التطبيقات" الخطرة. بديلهما صورة داخل صورة وإشعار التحكم

## المسار L: سطح مكتب لينكس (Debian + Xfce) بوضعين

**الهدف:** نظام شبيه بالحاسوب يدعم اللمس، لتشغيل MT5 للحاسوب ونماذج الذكاء الاصطناعي.

| | 🔒 وضع العزل (QEMU) | ⚡ الوضع السريع (proot) |
|---|---|---|
| التشغيل | نظام مستقل بنواة خاصة، محاكاة برمجية | على معالج الهاتف مباشرة |
| MT5 للحاسوب / الذكاء الاصطناعي | ❌ بطيء جدًا | ✅ (Box64 + Wine / llama.cpp) |
| التطبيق | SpirOS | **SpirOS Linux** (نسخة منفصلة، targetSdk 28) |

- **لماذا نسخة منفصلة؟** أندرويد 10+ يمنع التطبيقات الحديثة من تشغيل برامج من مساحتها الخاصة (W^X). التطبيقات المبنية لأندرويد 9 (مثل Termux) مستثناة. لذلك يأتي الوضع السريع في نسخة `speed` (`com.spiros.app.speed`) تُثبَّت بجانب SpirOS، ويبقى SpirOS الأساسي بكامل الحمايات.

### L1: نظام Debian + Xfce يُبنى تلقائيًا ✅
- [x] `linux/build-rootfs.sh` و`.github/workflows/linux-rootfs.yml`: Debian 13 (trixie) مع Xfce وTigerVNC ولوحة مفاتيح اللمس Onboard وخطوط عربية وبايثون، لمعالجات arm64 وamd64، ويُنشر مع بصمة SHA-256 في إصدار `linux-rootfs`
- [x] `spiros-desktop`: خادم Xvnc على ملف socket خاص (بدون منفذ شبكة) + جلسة Xfce

### L2: نسخة SpirOS Linux (الوضع السريع) ✅ بانتظار الاختبار
- [x] proot من Termux مضمّن في التطبيق مع loader الخاص به
- [x] تنزيل النظام، والتحقق من بصمته، وفك ضغطه (tar.xz) داخل التطبيق مع الروابط الرمزية والصلاحيات
- [x] ملفات /proc بديلة للملفات التي يحجبها أندرويد
- [x] سطح المكتب بملء الشاشة: لمسة = نقرة، وضغط مطوّل = الزر الأيمن، وسحب، وتمرير، وكتابة، واختيار حجم الشاشة
- [x] في SpirOS الأساسي: زر "لينكس" يشرح الحاجة إلى النسخة السريعة ويعطي رابط تنزيلها

### L3: اختبار آلي ✅
